MUSIK: tombol “Putar Musik & Buka Kejutan” memuat lagu melalui pemutar YouTube setelah sentuhan pengguna. Browser Android dapat membatasi autoplay atau pemutaran di latar belakang; jika terjadi, tekan Play pada pemutar Playlist. Pemutar YouTube tetap tertanam di halaman.

CARA DEPLOY:
1. Buat repository GitHub baru dengan visibility Public.
2. Upload index.html dan kelima foto di atas ke folder root.
3. Commit changes.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Tunggu deployment selesai, lalu buka URL GitHub Pages repository baru.
